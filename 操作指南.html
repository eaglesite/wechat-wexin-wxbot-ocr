一、它是怎么工作的

一次回复要经过五道关，任何一道没过就不会发送。

读取靠屏幕识别（不改微信、不注入、不登录网页版）；发送靠模拟键鼠。所以微信窗口需要保持打开——最小化或退出到托盘会读不到。

二、五分钟上手

按顺序做完这四步，就能收到第一条自动回复。

  1. 1
    配一个 AI（可跳过）

    「配置 → AI 设置」→ 选一个服务商 → 填模型与 API Key → 保存后点测试，看到成功再点设为默认。只打算用固定话术回复的话，这一步可以跳过。

  2. 2
    写几条常用规则

    「配置 → 触发规则」→ 新建，填关键词和回复。一条规则可以写多个同义关键词、多条话术随机轮换。内置了 30 条寒暄规则，开箱就能用。

  3. 3
    上传资料（可选）

    「知识库」→ 拖入产品手册 / 常见问答。支持 txt、md、pdf、docx、pptx、xlsx 和图片（图片自动 OCR）。AI 回答前会先查资料。

  4. 4
    划定范围并开启监控

    「配置 → 微信设置」→ 先用一键校准区域识别聊天区与会话列表 → 选好监控对象 → 点顶部开启监控。首次开启会自动校准一次。

提示：开启监控之前的旧消息只读不回。只有开启之后收到的新消息才会触发回复，避免一开程序就把历史消息全回一遍。

四、监控对象：只碰你允许的会话

这是全程序最重要的一项设置。名单之外的会话，程序不读、不回，也不会把微信切过去。

全部群和用户所有会话都处理。all
全部群只处理群聊，私聊不动。groups
全部用户只处理私聊，群不动。users
仅名单内只有下面列出的群或人。only
排除名单除了下面列出的，其他都处理。except
名单怎么填逗号分隔，或用「拾取当前会话」「扫描勾选」。

每收到一条消息都会先过这道闸

保存监控对象后会立刻生效，之前因为「不在名单」被跳过的会话也会重新参与判定。群身份判不准时，程序会结合标题、已学到的分类和聊天区的群系统提示行来判断。

群消息默认「被 @ 才回」

监控范围只管「哪些会话要管」，群里每条消息回不回，还有一道默认开关：群里只有 @ 你的消息才自动回复（微信设置 → 监控对象下方的「群消息需要被 @ 才自动回复」，默认勾选）。

  • 勾上（默认）：群里不 @ 的闲聊一律不回，避免插话；被 @ 的消息正常走规则 / 知识库 / AI。
  • 取消勾选：群里所有消息都自动回复，适合客服群、接单群这类场景。

被「未 @ 跳过」的群消息会在实时日志里显示为一行 [信息]「群消息未@，已跳过【群名】」——这是按设计跳过，不是发送失败；真正发送失败会显示「发送失败」的原因文字。

建议：第一次用先选「仅名单内」，只填一两个自己的测试群或小号。确认稳定后再放宽，避免误回客户或家人。

五、一条回复是怎么被选出来的

严格按顺序，前一层命中就不再往后走。这样规则永远最优先，AI 不会抢话。

1 触发规则关键词命中任意一条即回复。一条规则可配多条话术随机轮换，不会每次都一样。 命中即停
2 知识库用真实消息去检索已上传资料，找到足够相关的片段就据此作答，并标注 [知识库] 与来源文件。 有答案才用
3 AI带上最近几条对话和人设提示词请求模型；多配置按主 / 备顺序，主挂自动切备用。 兜底

三层都没结果、或额度用完时，程序不会硬编一句话发出去，而是记录原因并在界面提示。规则命中的优先级高于知识库和 AI——这是刻意设计的，方便你用固定话术压住重要场景。

六、状态灯与只读模式

三盏灯永远可见，扫一眼就知道哪里出了问题。

状态灯含义怎么办
绿色通道正常、AI 可用、知识库已就绪不用管，正常工作
黄色降级：AI 熔断 / 限流 / 未配置，但规则仍能回点灯进设置检查，或等冷却结束
红色断开或不可用：微信读不到、接口报错点灯看原因，按提示修复
灰色未开启或未配置开启监控 / 补配置

看到「只读模式 · 发送需管理员」怎么办

能读消息，但点不动微信、字也打不进去。原因是 Windows 的 UIPI：低权限程序不能向高权限窗口发送模拟输入。

  • 1关掉 WxBot。
  • 2右键 WxBot.exe →「以管理员身份运行」→ 弹窗点「是」。
  • 3重新打开后灯变绿即可发送。只想读消息的话，不处理也能继续用。

程序最多只申请一次提权，被拒绝就以只读模式继续，不会反复弹窗。想彻底不要 UAC，可用 WxBot.exe --no-elevate 启动。

七、首次运行可能看到的三种提示

都不是报毒。按下面处理，之后基本不会再出现。

1
「Windows 已保护你的电脑」/ 未知发布者

这是 SmartScreen 对未签名 + 网络下载文件的信誉拦截。解压前右键压缩包 →「属性」→ 勾选解除锁定 → 再解压；已经解压过的，在该目录打开 PowerShell 执行 Get-ChildItem -Recurse | Unblock-File。

程序首次启动后会自己清除下载标记，第二次起不再出现。想第一次就避免，解压前先解除锁定；要彻底消除（换电脑、重新下载也不提示）只能使用受信任的代码签名证书。

2
UAC「是否允许此应用对你的设备进行更改」

只有微信以管理员身份运行、或本程序被系统降权时才需要。点「是」只弹这一次；点「否」程序也会继续以只读模式运行，不会退出，也不会再弹第二个提示框。

提权前程序会先清掉下载标记并跳过重复的 zone 检查，所以不会出现「打开文件 - 安全警告 / 无法验证发布者」，需要提权时最多只剩这一道 UAC。

3
杀毒软件 / 安全卫士提示「有风险」

无签名 + 模拟点击的程序常见误报。把 WxBot 整个目录加入信任 / 排除项即可。程序不会、也无法替你关闭安全软件。

八、发不出去？按这个顺序查

从最常见的开始，逐条排除，通常前两步就能解决。

  • 微信收不到自动回复
    • ① 三盏灯里有红灯 → 点红灯进对应设置，先修通道 / AI / 知识库。
    • ② 顶部「自动回复」总开关是否关着 → 打开。
    • ③ 这个会话在监控对象里吗 → 不在就加名单，或换成「全部用户 / 全部群」。
    • ④ 微信窗口是否最小化 / 收进托盘 → 恢复窗口；被其他窗口遮挡不要紧。
    • ⑤ 是否显示「只读模式」→ 右键以管理员身份运行（见上一节）。
    • ⑥ 是否超过免费额度（每天 50 条）→ 看工作台今日统计。
    • ⑦ 以上都正常 → 点「读取自检」，它会逐环节报告窗口、截图、标题、监控范围和消息识别哪一步失败。
  • 能识别消息，但回复内容不对
    • ① 消息上标的是 [规则] → 关键词太宽，收窄关键词或降低该规则优先级。
    • ② 标的是 [知识库] 但答偏了 → 检查资料原文，或换更明确的问法测试。
    • ③ 标的是 [AI] → 先点测试确认接口正常，再调整人设提示词。
  • 识别错字 / 漏消息
    • ① 微信窗口太窄 → 在「微信设置 → 高级」开「布局锚定」，不足半屏宽时自动补齐。
    • ② 窗口位置固定 → 勾「固定读取区域」加快读取、减少误判。
    • ③ 重新点一次「一键校准区域」。

九、常见问题

点标题展开答案。

它会一直抢我的鼠标和键盘吗？

不会。空闲时只做不点击的后台检查；只有确定有新消息要读取或发送时才切换会话并前置微信。勾选「你操作时不打扰」后，你动键鼠时它会先等你停手。

微信窗口一定要放在最前面吗？

不需要置顶，也不能最小化。窗口被其他程序遮住仍可读取；最小化或退出到托盘后就读不到了。发送时程序会自己把微信切到前台。

开启监控后，历史消息会被回复吗？

不会。开启之前的消息只读不回，只有开启之后新收到的消息才触发回复。

免费版有哪些限制？

每天 50 条自动回复、5 条自定义规则、1 个 AI 配置、知识库 10 MB。内置的 30 条常用规则不计入自定义额度。激活授权后解除限制。

换电脑后授权还能用吗？

授权与机器码绑定。机器码在首次运行时按本机信息生成并写入 data/machine_id.txt，不随安装包附带。换机后需要重新申请或迁移授权。

数据会上传到服务器吗？

聊天记录、配置、知识库都只存在本机 data 目录。只有在你配置了云端 AI 时，消息内容才会发给你选的模型服务商；授权校验会联网。两者都可在设置里查看。

想临时全部停掉怎么办？

关掉顶部的「自动回复」总开关，或点「停止监控」。前者仍记录消息但不发送；后者连读取也停下。托盘菜单里也有「暂停」。

关闭窗口后程序还在后台吗？

默认关闭主窗口即退出进程。需要常驻时用托盘菜单，托盘里保留「打开界面 / 暂停 / 退出」。
